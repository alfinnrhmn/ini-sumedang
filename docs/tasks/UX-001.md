## Tujuan
Lima permintaan pemilik 3 Nov 2026: hero Beranda berganti otomatis; halaman kategori (selain Berita) tanpa "Terbaru dan Terpopuler", kolom kanan = Ikuti IniSumedang, Trending, Advertisement, plus tombol "Lebih banyak"; teks "Lainnya" Beranda diperbesar; kolom kanan menempel (sticky). Butir 5 permintaan kosong, tidak dikerjakan.
## Keputusan yang masih berlaku
1. **Hero otomatis.** `HERO_AUTOPLAY_MS = 5000` (`app/config/home.ts`), putar berulang 1→4→1; jeda saat hover, `:focus-visible` di hero, tab tersembunyi; klik titik/panah memulai ulang timer; `prefers-reduced-motion` = tanpa putar; hanya di klien setelah mount, < 2 slide tanpa timer; `aria-live` `off` saat berputar, `polite` saat dijeda.
2. **Kolom kanan kategori (selain Berita).** `SocialWidget` → **Trending** (`TrendingList.vue`, dari `sidebar.popular`, `SIDEBAR_COUNT` 4; kosong = tidak dirender; tanpa API baru) → iklan; tanpa tab Terbaru|Terpopuler. Beranda (= Berita) tetap memakai tab.
3. **"Lebih banyak"** (`LoadMore.vue`) menggantikan paginasi: tautan `?halaman=N+1` (`rel="next"`), tanpa JS tetap navigasi biasa; dengan JS `$fetch` dan menambah kartu tanpa duplikat (`mergeArticles`), satu permintaan sekaligus, `aria-busy`, pesan gagal netral, `role="status"` "N berita ditambahkan", fokus ke judul kartu baru, tombol hilang di halaman terakhir. Tombol `--color-brand` teks putih (5,0:1), tinggi 44, radius 8.
4. **"Lainnya"** di `SectionTitle`: mobile 14 px / desktop 16 px (panah sama), lebih kecil dari judul; judul ber-`max-width` agar tidak tumpang tindih sampai 320 px.
5. **Sticky** hanya ≥ 1024 px: `useStickyColumn` dengan `top = min(24, innerHeight - tinggiKolom - 24)` (`stickyTop` murni; default 24 px tanpa JS); pada `.side-ads`, `.section-ad` (Beranda), `.sidebar-col` (Detail), `.secondary` (kategori); < 1024 `static`.
6. **Perbaikan F1.** `focusin`/`focusout` + `stickyTopForFocus` menjaga fokus keyboard tetap terlihat di kolom sticky tinggi; kembali ke rumus saat fokus keluar, `resize`, atau gulir > 8 px.
7. Tanpa dependensi, token, font baru; `nuxt.config.ts` dan `package.json` tidak berubah; `v-html=` satu baris.
## Kriteria penerimaan
1. Hero berganti tiap 5 detik dengan animasi yang ada, jeda/restart/reduced-motion benar, tanpa layout shift atau timer sisa.
2. Kategori selain Berita: tanpa tab; kolom kanan widget → Trending → iklan; Beranda/Detail tidak berubah isi.
3. "Lebih banyak" berfungsi dengan dan tanpa JS, tanpa duplikat, status dan fokus dapat diakses.
4. "Lainnya" lebih besar dari sebelumnya, lebih kecil dari judul, 0 tumpang tindih sampai 320 px.
5. Sticky sesuai rumus di 1440×900/1280×720/1024×768 tanpa menimpa footer; < 1024 tanpa sticky; posisi awal identik; `lint`, `typecheck`, `npm test`, `build` kode 0.

## Catatan
- **Terbuka untuk pemilik:** (a) **F2** tombol jeda autoplay (WCAG 2.2.2, Medium; PRD §13 butir 11, POLISH-01): gerakan otomatis > 5 detik, jeda hover/fokus/reduced-motion belum cukup bagi pengguna sentuh; (b) **AGENTS.md aturan 1** menyebut Trending tidak ada: sesuaikan kalimatnya karena yang ditambah adalah bagian di kolom kanan kategori (bukan halaman); (c) tab Terbaru|Terpopuler di Beranda **tidak menempel** (tingginya sama dengan hero); (d) butir 5 permintaan kosong.
- **Low terbuka/diterima:** F3 (tanpa JS `top` tetap 24 px), F4 (Back/Forward kehilangan kartu tambahan "Lebih banyak"), F5 (klik beruntun sangat cepat), F6 (anchor tidak aktif dengan Spasi; tanpa JS tidak ada "Sebelumnya"; autoplay jalan saat hero di luar layar), N1 (kolom melompat ke posisi rumus saat fokus keluar/gulir), N2 (klik tautan < 24 px dari tepi menggeser kolom 15–52 px), N3 (cincin fokus 4 px bisa terpotong di tepi atas saat menempel di dasar kontainer).
- `app/components/category/Pagination.vue` dihapus (diganti `LoadMore.vue`).
- **Deviasi POLISH-01:** tombol "Lebih banyak", bagian Trending, "Lainnya" 14/16 px (Figma 11,1/10). Tidak teruji: autoplay di perangkat sentuh nyata, tab tersembunyi dan reduced-motion OS sungguhan, `resize` live, pembaca layar, Safari/Firefox.
