## Kriteria penerimaan (draf)
1. Header desktop dan mobile sesuai geometri `21:5360`/`116:1662` (ukuran, radius, jarak) pada 1440 dan 402.
2. Menu kategori dibuat dari kategori WordPress (bukan teks Figma); 9 kategori resmi; tautan biasa ke `/kategori/[slug]`; ejaan "Politik", "Otomotif", "Jelajah".
3. Slot pencarian ada di header (input desktop, ikon mobile); perilakunya milik PAGE-004. **[I]** usulan PM, perlu konfirmasi.
4. Footer: logo, tagline, 6 ikon sosial (URL dari konfigurasi, `https`, `rel="noopener noreferrer"`), kolom/baris sesuai desain, legal; tanpa panel berlangganan.
5. Fokus keyboard terlihat; landmark `header`/`nav`/`footer`; tanpa overflow horizontal; tablet 768–1023 sesuai PRD §3.4.
6. Warna/spasi lewat token SET-002; tanpa nilai literal.
