## Catatan
- **Lint pertama gagal** di proyek: `Cannot find module '.nuxt/eslint.config.mjs'`. File itu dihasilkan Nuxt (`nuxt prepare`); ia ada setelah `npm run typecheck`. Pada salinan bersih, `npm ci` (yang menjalankan `postinstall` = `nuxt prepare`) sudah cukup sehingga lint langsung lulus, jadi urutan CI `npm ci → lint` valid. Bila lint dijalankan tepat setelah mengubah modul tanpa `nuxt prepare`, kegagalan itu bisa muncul lagi.
- 7 kerentanan **low** (`deepmerge` GHSA-gcqx-w48m-w2h4) berasal dari rantai `nuxt → nitropack → @rollup/plugin-node-resolve → deepmerge`, bukan dari paket baru. `npm audit fix --force` menawarkan menurunkan `nuxt` ke 4.1.3: **tidak boleh dilakukan** (menurunkan di bawah 4.5.1, PRD §10.1). Perlu penilaian tertulis PM/pemilik (kriteria 5).
- Peringatan non-peer: `npm warn deprecated glob@10.5.0` pada `npm ci`, dependensi turunan.
