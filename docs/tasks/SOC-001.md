## Tujuan
Menampilkan kembali widget "Ikuti IniSumedang": judul + subjudul + 6 kotak (Facebook, Instagram, X, YouTube, TikTok, WhatsApp; ikon + nilai + satuan). Fungsi: menampilkan jumlah pengikut akun IniSumedang, bukan fitur follow: tanpa tombol ikuti, SDK, atau tautan sampai URL akun diberikan pemilik.
## Di luar scope
Angka dari WordPress/API platform, tombol ikuti/SDK, pelaporan klik, Detail mobile (tidak ada di Figma).
## Keputusan yang masih berlaku
1. **Posisi.** Beranda desktop: kolom kanan paling atas sejajar kartu pertama Rekomendasi, iklan kembali ke y Figma (1079,95 / 1348,95). Detail desktop: kolom kanan paling atas (iklan +232). Kategori: kolom kanan urutan tab → widget → iklan. Beranda mobile: setelah section "Bisnis dan Teknologi". Detail mobile/tablet: tanpa widget. Beranda memuat dua salinan (desktop dan mobile, satu `display: none`).
2. **Komponen.** `app/components/home/SocialWidget.vue`, `<aside>` dengan judul `h2`, ukuran tetap 357×200 (354×200 mobile); data `app/config/social.ts` (`name, icon, value, unit, url?`); ikon `public/icons/social-stat-*.svg` dari Figma.
3. **Tautan.** Kotak = teks biasa selama `url` kosong; `url` `https://` (spasi awal dipangkas) = `<a rel="noopener noreferrer" target="_blank">`; `http:`/`javascript:`/`data:`/`//host`/kredensial tetap teks. Nama aksesibel "Facebook, 12,4K Pengikut"; ikon `aria-hidden`; kotak bukan tab stop tanpa `url`.
4. **Warna.** `#1F2937` (nilai) → `--color-footer-link` `#172033` (selisih 8/9/4, deviasi); `#F5F5F5` → `--color-surface`; lainnya persis token. Tanpa dependensi, token, font baru; `nuxt.config.ts` tidak berubah.
## Kriteria penerimaan
1. Widget sesuai `101:2601`/`127:2810`/`100:2447` (selisih ≤ 1 px, tinggi teks ±2 px) di posisi keputusan 1.
2. Angka dari `app/config/social.ts`; tanpa tombol/form/SDK/skrip; `url` https menjadi tautan aman; a11y (heading, nama aksesibel, kontras ≥ 4,5:1).
3. Tanpa layout shift; komponen lain tidak berubah ukuran.
4. `lint`, `typecheck`, `npm test`, `build` kode 0; `v-html=` tetap satu baris.
