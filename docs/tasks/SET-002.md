### Definisi subset Latin (T8; menerima usulan QA S32)
Tiap berkas `woff2` memuat **minimal** glif: U+0020–007E, U+00A0–00FF, U+2013, U+2014, U+2018, U+2019, U+201C, U+201D, U+2022, U+2026, U+20AC. Tanpa `unicode-range` di `@font-face` (satu berkas per bobot; berkas sudah di-subset). Lebih banyak glif boleh (mis. subset "latin" bawaan sumber resmi) asal himpunan minimum ada. FE melaporkan cakupan dan ukuran.

## Kriteria penerimaan
1. `app/assets/css/tokens.css` memuat **tepat** token pada "Spesifikasi final token" (nama dan nilai persis: 22 nilai warna + 3 alias, 2 famili, 18 gaya `--type-*`, 2 `--tracking-*`, 10 `--space-*`, 5 `--radius-*`, 2 `--container-*`), di satu `:root`, tanpa token lain; tiap nilai diberi komentar sumber (variabel/node) atau penanda `[usulan]`.
2. Inter (bobot 300, 400, 500, 600) dan Merriweather SemiBold (600) disajikan dari berkas lokal; tiap `@font-face` memuat **`font-display: swap`**, subset **Latin** (glif minimum pada "Definisi subset Latin"), format `woff2`, tanpa `unicode-range`; **berkas lisensi resmi tiap font ada di `public/fonts/`** (teks asli dari sumber resmi, bukan tebakan); tidak ada permintaan ke `fonts.googleapis.com` / `fonts.gstatic.com` saat build maupun runtime.
3. Outfit dan Merriweather Sans **tidak** ada di berkas CSS, aset, maupun `package.json`.
4. `app/assets/css/base.css` berisi **hanya** sembilan selektor pada "Isi `base.css`" dengan deklarasi di sana (reset minimum, `box-sizing`, dasar `body` dari `--type-body`/`--color-text`/`--color-background`, `:focus-visible` 2 px solid `--color-focus` offset 2 px, `prefers-reduced-motion` dihormati); **tanpa warna literal** (hex/rgb/hsl) di luar `tokens.css`; tanpa kelas komponen.
5. `tokens.css` dan `base.css` dimuat global (lewat impor di `app/app.vue`; `nuxt.config.ts` tidak diubah).
6. Laporan kontras di Bukti: tiap pasangan teks/latar yang dipakai di 4 frame final dihitung (rumus WCAG); teks normal ≥ 4,5:1, teks besar ≥ 3:1; pasangan yang gagal ditandai dan **token yang gagal AA (Gray 3/4/5, Info, Success, Warning, Error) tidak ditetapkan sebagai warna teks** di `base.css`.
7. Tidak ada dependensi baru: `package.json` dan `package-lock.json` tidak berubah.
8. `npm run lint`, `npm run typecheck`, `npm run build` kode 0 (keluaran nyata dilaporkan).
9. Tidak ada komponen/halaman baru, tidak ada file `.env`, tidak ada perubahan di luar "File yang boleh disentuh".
