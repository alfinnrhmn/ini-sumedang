## Tujuan
Satu sumber token (CSS custom properties) dan font self-host untuk semua komponen berikutnya, tanpa warna literal di komponen. Bukan komponen: tanpa header, kartu, tombol, atau halaman.

## Di luar scope
Komponen fitur, halaman, animasi, Merriweather Sans, library UI/Tailwind, dark mode, perubahan `app/` selain impor CSS.

## Keputusan yang masih berlaku
- Font: Inter 300/400/500/600 + Merriweather 600, `woff2` Latin di `public/fonts/` (opsi A, tanpa dependensi), `font-display: swap`, tanpa 700/italic, berkas lisensi resmi disertakan. Outfit tidak dipakai; Merriweather Sans diputuskan saat task hero.
- `app/assets/css/tokens.css`: satu `:root`, px, tepat 22 nilai warna + 3 alias (`--color-text`, `--color-background`, `--color-focus`), 2 famili, 18 gaya `--type-*`, 2 `--tracking-*` (-0,72 px / -0,2 px), spacing 10 nilai (8–120), radius 6/8/10/16 + `full`, `--container-desktop` 1120 / `--container-mobile` 354. `@font-face` boleh di `tokens.css`.
- Warna: `#F3F7FF` dikeluarkan sampai ada pemakainya; `#1A212E` tidak dibuat. Token gagal AA (Gray 3/4/5, Info, Success, Warning, Error) bukan warna teks.
- `app/assets/css/base.css`: hanya sembilan selektor (reset minimum, body dari token, `:focus-visible` 2 px solid `--color-focus` offset 2 px, `prefers-reduced-motion`); tanpa warna literal.
- Impor global di `app/app.vue`; `nuxt.config.ts` tidak diubah. Glif minimum: U+0020–007E, U+00A0–00FF (tanpa U+00AD), U+2013/2014/2018/2019/201C/201D/2022/2026/20AC.
- Nama internal berkas Merriweather ("Merriweather Light 18pt") diterima; yang dinilai family di `@font-face`, bobot, SHA-256.
- Risiko Reserved Font Name Merriweather (woff2 turunan Fontsource 5.3.0) diterima pemilik: `docs/decisions/0004-merriweather-rfn.md`.

## Kriteria penerimaan
1. `tokens.css` memuat tepat token pada keputusan di atas, tiap nilai bersumber/ditandai `[usulan]`.
2. Font dari berkas lokal, `swap`, subset Latin, `woff2`; lisensi resmi ada; tanpa permintaan ke host font pihak ketiga.
3. Outfit dan Merriweather Sans tidak ada di CSS, aset, `package.json`.
4. `base.css` hanya sembilan selektor, tanpa warna literal atau kelas komponen.
5. Token dan base dimuat global lewat `app/app.vue`.
6. Kontras pasangan terpakai ≥ 4,5:1 (teks normal); token gagal AA bukan warna teks.
7. Tanpa dependensi baru; lint, typecheck, build kode 0; tanpa komponen/halaman baru.

## File yang disentuh
`app/assets/css/tokens.css`, `app/assets/css/base.css`, `app/app.vue` (impor CSS), `public/fonts/**` (woff2 + lisensi), berkas ini.
