## Tujuan
Satu sumber token (CSS custom properties) dan font self-host yang dipakai semua komponen, tanpa warna literal di komponen (PRD §3.7).

## Node Figma
Token dibaca dari 4 frame final. Bukti: `docs/FIGMA-INVENTORY.md` §A (tipografi, warna, spacing, radius, shadow).

| Node | Peran |
|---|---|
| `21:4950`, `130:515`, `90:1611`, `130:2945` | sumber `get_variable_defs` |

## Di luar scope
Dark mode (token gelap tidak dibuat; hanya struktur variabel yang memudahkan nanti), komponen fitur (header, kartu, dst.), animasi, library UI/Tailwind.

## Kriteria penerimaan (draf; final setelah keputusan)
1. `app/assets/css/tokens.css` memuat custom properties untuk warna, tipografi, spacing, radius dari inventaris; tiap nilai punya penanda sumber (node/variabel) atau ditandai usulan.
2. Font **yang diputuskan pemilik** di-self-host (`font-display` diatur); tidak ada permintaan ke Google Fonts saat runtime.
3. `base.css`: reset minimum, fokus terlihat, ukuran dasar; tanpa warna literal di luar `tokens.css`.
4. Laporan kontras: pasangan teks/latar yang dipakai di 4 frame final dihitung (rumus WCAG); pasangan yang gagal AA ditandai.
5. Tidak ada dependensi baru kecuali yang disetujui (mis. `@nuxt/fonts`) — **[APPROVAL]**.

## Rencana tes (QA)
Disusun setelah BLOCKED dibuka. Minimal: nilai token = nilai Figma pada tabel inventaris; font tampil dari berkas lokal (tab Network tanpa host font pihak ketiga); tidak ada `#hex` literal di `app/components/**` (grep); kontras pasangan terpakai ≥ 4,5:1 (teks normal) atau ≥ 3:1 (teks besar); layout 1440 dan 402 tidak bergeser akibat font (CLS).

## File yang boleh disentuh
`app/assets/css/**`, `app/app.vue` (hanya impor CSS), `public/fonts/**`, `nuxt.config.ts` (hanya `css`/modul font) **[APPROVAL]**, `package.json` **[APPROVAL]**.
