## Tujuan
Iklan di slot Beranda, Detail, dan kategori berasal dari konten "Iklan" di WordPress (ACF): gambar + tautan + slot + jadwal + aktif. Editor mengganti iklan tanpa menyentuh kode.

## Di luar scope
Penghitung tayangan/klik, skrip penyedia iklan, HTML mentah, rotasi lebih dari satu iklan per slot, halaman opsi ACF Pro, penulisan ke WordPress.

## Keputusan PM
1. **Struktur ACF (dibuat pemilik).** Post Type `iklan` (Show in REST API aktif, REST base `iklan`). Field group "Detail Iklan" untuk post type itu (Show in REST API aktif; field tampil di properti `acf` respons) dengan field: `gambar` (Image, return format **Image Array**), `tautan` (URL), `slot` (Select; nilai persis `sidebar-s`, `sidebar-m`, `sidebar-l`, `mobile-s`, `mobile-m`, `wide-m`, `wide-l`), `aktif` (True/False), `mulai` dan `selesai` (Date Picker, return `Y-m-d`, opsional), `teks_alt` (Text, opsional). Judul post = nama internal iklan.
2. **Sumber.** Mode WordPress (`NUXT_WP_BASE_URL` valid): `GET wp/v2/iklan?status=publish&per_page=100&_fields=id,date_gmt,title,acf&acf_format=standard` (tanpa `acf_format=standard`, ACF mengirim gambar sebagai ID, bukan Image Array; ditemukan saat uji ACF asli 6 Nov) lewat klien yang ada (cache 60 dtk, single-flight, timeout, tanpa kredensial) lewat endpoint baru `/api/ads` → `{ source: 'wordpress', ads: { [slot]: { id, image: {url}, alt, href } } }`. Mode fixture: `{ source: 'fixture', ads: {} }`.
3. **Pemilihan.** Iklan layak bila: `aktif` benar; `slot` salah satu dari 7 nama; `gambar.url` lolos `safeImageUrl` (https host WordPress); `tautan` berupa `https://` valid (tanpa userinfo, ≤ 2048 karakter); jadwal: hari ini (WIB, UTC+7) di antara `mulai` dan `selesai` inklusif (kosong = tanpa batas; format tak valid = iklan dibuang). Per slot dipakai satu iklan: yang `date_gmt`-nya terbaru (lalu id terbesar). Semua data tak layak dibuang tanpa galat.
4. **`AdSlot`.** `source = fixture`: penampung "Advertisement" seperti sekarang (fixture/QA tidak berubah). `source = wordpress`: ada iklan → `<aside aria-label="Iklan">` berisi tautan `<a href rel="sponsored noopener noreferrer" target="_blank">` + `<img>` (alt = `teks_alt` atau judul) di kotak berukuran tetap slot (`object-fit: cover`, tanpa layout shift) dengan label kecil "Iklan" (token yang ada); tidak ada iklan atau data gagal dimuat → slot TIDAK dirender (tanpa kotak kosong). Kegagalan `/api/ads` tidak boleh menggagalkan halaman. Data dimuat satu kali (kunci `ads`, dibagikan semua slot, SSR tanpa hydration mismatch).
5. **Keamanan.** Tidak ada HTML/skrip dari CMS; gambar dari host WordPress saja; teks alt/judul sebagai teks; tautan hanya `https`; galat tanpa URL/stack. Tanpa dependensi; `nuxt.config.ts` tidak berubah.

## Kriteria penerimaan
1. Mode fixture: semua halaman identik dengan sekarang (placeholder, rect, `/api/*` lain); uji lama lulus.
2. Mode WordPress dengan tiruan ACF: iklan aktif tampil di slot yang benar (7 slot, Beranda/Detail/kategori/mobile), tautan benar dan aman; tidak aktif, di luar jadwal, slot salah, gambar tak aman, tautan `http:`/`javascript:`/berisi userinfo = tidak tampil; slot tanpa iklan tidak dirender; dua iklan satu slot = yang terbaru.
3. WordPress mati, ACF tanpa `acf`/post type `iklan` tidak ada (404), JSON rusak: halaman tetap tampil, slot tidak dirender, tanpa galat 5xx pada halaman.
4. Tanpa layout shift; tab stop hanya tautan iklan; fokus terlihat; konten berbahaya (judul/alt ber-HTML, `javascript:`) tidak tereksekusi.
5. `lint`, `typecheck`, `npm test` (uji murni untuk normalisasi, jadwal WIB, pemilihan), `build` kode 0; `v-html=` satu baris.
