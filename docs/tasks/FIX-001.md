## Keputusan pemilik / PM yang berlaku
1. **Fixture default (set `figma`)** = 8 artikel `publish`. Judul dan nama penerbit = **teks aktual** dari `get_design_context` (bukan nama layer). Label kategori = salah satu dari 9 kategori resmi (Berita, Nasional, Pemerintahan, Politik, Hukum, Sepak Bola, Otomotif, Jelajah, Bisnis & Teknologi), **bukan** salah ketik Figma ("Politic", "Otomatif", "Jalajah"). Bila label di Figma tidak jelas cocok dengan satu kategori resmi, FE memilih yang paling dekat dan mencatat pilihan di Bukti [I]; tidak menebak diam-diam.
2. **Waktu relatif** dihitung dari `now` (menit lalu dst. sesuai teks Figma: selisih menit/jam dari Figma diubah menjadi offset dari sekarang) agar tampilan "x menit lalu" terjaga.
3. **Gambar** diambil dari Figma lewat MCP (aset di `get_design_context` atau alat unduh aset), disimpan lokal di `public/fixtures/`, **menggantikan 4 SVG gradien** (`img-1..4.svg` dihapus). Bila gambar unik < 8, dipakai ulang. **Unduhan ini disetujui pemilik.** FE melaporkan ukuran tiap berkas (byte). Bila ada > 300 KB: usulkan pengaturan ekspor lebih kecil (mis. skala/format ekspor Figma) di Bukti; **tidak** memasang alat konversi, **tidak** menambah dependensi.
4. **Set `edge`** = fixture kasus buruk yang ada saat ini (12 terbit + draft/private: judul ≥ 150 dan ≤ 15 karakter, tanpa gambar, gambar tanpa `alt`, entitas `&amp;`/`&#8211;`/`&#8217;`/`&#8230;`, kategori ber-entitas, kategori kosong dan tag kosong bila belum ada → ditambahkan). Aktif **hanya** jika env `FIXTURE_SET=edge`; tidak diset (atau nilai lain) = set `figma`. Set `edge` memakai gambar Figma yang diunduh (bukan SVG lama).
5. **Variabel `FIXTURE_SET`** dibaca server dari `process.env` di `server/services/articles.ts` (tanpa mengubah `nuxt.config.ts`/`runtimeConfig`). Didokumentasikan di `.env.example` sebagai baris komentar tanpa nilai rahasia, dan di bagian Catatan berkas ini. QA memakai `FIXTURE_SET=edge` untuk pemeriksaan kasus buruk.
6. **Hak pakai gambar:** gambar fixture berasal dari Figma, hanya untuk pengembangan, **WAJIB dihapus sebelum situs tayang** (digantikan konten WordPress). Dicatat sebagai item wajib pra-tayang di PRD §13.
7. Kompleksitas minimal: dua fungsi pembangun (`buildFigmaPosts`, `buildEdgePosts`) di `server/fixtures/`, satu pemilih kecil di `articles.ts`. Tidak ada abstraksi/library baru. Filter `publish`, mapper, dan pengurutan di `articles.ts` tidak diubah.
