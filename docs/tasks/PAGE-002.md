## Keputusan PM
1. **Rute dan tautan.** `app/pages/berita/[slug].vue`. `articlePath(article)` = `/berita/<slug>` (satu-satunya tempat bentuk URL). Semua kartu artikel berlaku: `NewsCard` (semua varian), kartu Ruang Visual (`VisualTopic.vue`), dan **judul slide hero** (`Hero.vue`; pola sama: judul = tautan, area klik seluruh kartu lewat overlay `::after`, **tepat satu titik tab per kartu**; gambar/thumbnail BUKAN tautan kedua; titik carousel tetap tombol terpisah dan dapat diklik/difokus di atas overlay). Kategori tetap teks biasa (`categoryPath` = `null`) sampai PAGE-003; breadcrumb: "Beranda" = tautan sungguhan ke `/`, kategori = teks biasa, judul = halaman saat ini (`aria-current="page"`, bukan tautan).
2. **Fokus dan hover kartu (tertunda sejak HOME).** Fokus: cincin global 2 px + offset 2 px (= 4 px total) pada kartu (`:focus-visible` pada tautan; cincin mengikuti bentuk kartu, tidak terpotong `overflow: hidden`). Hover (tidak digambar di Figma; turunan dari token): **judul bergaris bawah** (`text-decoration: underline`), tanpa perubahan warna (menjaga kontras), hanya pada perangkat dengan `@media (hover: hover)`; cursor pointer. QA memeriksa fokus dan hover kartu di Beranda, section, kolom samping, Ruang Visual, hero, dan Detail.
3. **Data dan API.** Layanan `getArticleBySlug(slug)` dan `getRelatedArticles(...)` di `server/services/` (fixture di balik fungsi). Endpoint tipis (mis. `server/api/article/[slug].get.ts`; hindari bentrok dengan `/api/articles/<nama statis>`) mengembalikan `{ article, related: { sidebar, bottom }, now }`, dengan **`bodyHtml` yang sudah lewat `sanitizeBodyHtml` di server**; **HTML mentah (`body`) tidak pernah keluar dari server** (tidak ada field `body`/`content` mentah di respons maupun payload SSR). Tipe domain `ArticleDetail` di `app/types/article.ts` (tambahan: `excerpt`, `bodyHtml`, `tags`, `photoCredit`, `readingMinutes`, kategori). **Validasi `slug`**: pola `^[a-z0-9]+(?:-[a-z0-9]+)*$` dan panjang ≤ 120; tidak cocok atau tidak ada atau `draft`/`private` → **404** (`createError` statusCode 404, pesan netral tanpa jejak tumpukan/echo masukan); respons mengabaikan query.
4. **Body.** `bodyHtml` kosong atau `''` (sanitizer menolak/di atas batas) → halaman tetap tampil (judul, foto, meta) dengan **pesan netral** di tempat isi ("Isi artikel belum tersedia." atau serupa; tidak menyalahkan pengguna, tanpa detail internal) dan tombol bagikan/terkait tetap ada.
5. **`v-html` hanya di satu tempat.** `app/components/article/ArticleBody.vue` mengikat `bodyHtml` (string dari server) dengan `v-html` dan komentar `// eslint-disable-next-line vue/no-v-html` beserta alasan tertulis (HTML sudah disanitasi allowlist di server oleh `sanitizeBodyHtml`/SANITIZE-001; satu-satunya pemakaian). **Tempat lain dilarang**; `git grep -n 'v-html=' -- app server` harus **tepat satu baris**, di berkas itu (gerbang diperbarui di `.claude/commands/jalankan-slice.md`, butir 7 catatan pemilik). Komentar/dokumen tidak boleh memuat string `v-html=`. Gaya isi (paragraf, h2, daftar, blockquote "Baca Juga", gambar, tabel, iframe YouTube 16:9, tautan) lewat `:deep()` di komponen itu; semua dari token; **tanpa** `class`/`style` bawaan HTML (sanitizer membuangnya).
6. **Berita Terkait (PRD §3.8, FR-07).** Satu daftar berperingkat per artikel: berbagi **tag** (urut jumlah tag sama, lalu terbaru) → lengkapi **kategori sama** → lengkapi **terbaru**; hanya `publish`; tanpa artikel yang sedang dibaca; tanpa duplikat; **sidebar = 4 teratas (desktop), blok bawah = 3 berikutnya** (tanpa duplikat antar blok); mobile: blok bawah saja (3 pertama atau sesuai Figma mobile; FE membaca `130:2945` dan melapor). Sidebar berjudul **"Berita Terkait"** (G14 usulan; bukan "Trending"), tanpa "Lainnya". Kosong → blok disembunyikan (tanpa judul tanpa isi).
7. **Bagikan (FR-06, catatan pemilik 5).** Hanya yang ada di Figma **dan** punya URL bagikan https standar: **Facebook** (`https://www.facebook.com/sharer/sharer.php?u=<url kanonis>`) dan **X** (`https://x.com/intent/post?url=<url>&text=<judul>`; `twitter.com/intent/tweet` boleh bila FE mendokumentasikan alasan) = `<a target="_blank" rel="noopener noreferrer">` dengan nama aksesibel ("Bagikan ke Facebook/X"); **Instagram tidak dirender** dan dicatat untuk keputusan pemilik; **Salin tautan** = `<button>` yang menyalin URL kanonis lewat Clipboard API dengan umpan balik teks ("Tautan disalin" / "Tidak dapat menyalin tautan", `aria-live="polite"`), tanpa SDK pihak ketiga; **WhatsApp** tidak ada di Figma → tidak dirender (dicatat). URL kanonis = origin permintaan + `/berita/<slug>` (`useRequestURL()`; basis URL produksi ditetapkan saat hosting [I]); parameter di-`encodeURIComponent`.
8. **Metadata.** `useSeoMeta`/`useHead` (bawaan Nuxt, tanpa modul): `title` ("<judul> — IniSumedang"), `description` (ringkasan), `og:title`, `og:description`, `og:type=article`, `og:image` (foto utama bila ada), `canonical` (`useHead` link rel=canonical). `lang` dokumen mengikuti yang sudah ada.
9. **Tipografi dan warna.** Warna mengikuti aturan pemetaan PRD §4.5 (selisih ≤ 4 level per kanal RGB → token terdekat, kontras AA, dilaporkan). **`#1A212E`** (judul Detail, `130:3352`): bila selisih > 4 level per kanal dari **semua** token yang ada, **tambahkan token baru di `tokens.css`** (mis. `--color-article-title`, bukan inline; hanya penambahan baris) dan catat di POLISH-01 (PM yang mencatat). Merriweather 400 untuk isi, Inter 700), **jangan mengunduh berkas font baru**: pakai font di-host terdekat, catat deviasi (node, nilai Figma, nilai sekarang, penyebab) dan usulan; PM meminta persetujuan pemilik di akhir.
